ls -> Lista arquivos

cd -> Move entre diretórios

pwd -> Mostra o diretório de trabalho onde você está

mkdir -> Cria pasta

ls -a -> lista arquivos ocultos (./ ../ e outros)
	-> ./ = pasta atual
	-> ../ = pasta anterior/pasta pai (ex.: de um cd ../ e você retorna uma pasta)

rm - > remove arquivo ou diretório

rm -rf 'diretório' -> comando para apagar de forma recursiva e forçada todos diretórios/arquivo/pasta, cuidado com ele

cat -> exibe conteúdo do arquivo

git log -> mostra todos o histórico de commits
