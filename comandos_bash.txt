ls -> Lista arquivos

cd -> Move netre diretórios

pwd -> Mostra o diretório de trabalho onde você está

mkdir -> Cria pasta

ls -a -> lista arquivos ocultos (./ ../ e outros)
	-> ./ = pasta atual
	-> ../ = pasta anterior/pasta pai (ex.: de um cd ../ e você retorna uma pasta)

git init . -> Cria um repositório de acordo com a pasta atual de um 'pwd' antes de dar 'git 	      init .' para saber onde você está

rm -rf 'arquivo' -> comando para apagar arquivo/pasta, cuidado com ele

cat -> exibe conteúdo do arquivo
